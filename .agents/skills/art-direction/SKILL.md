---
name: hand-quest-art-direction
description: Use before designing Hand Quest screens, backgrounds, interface elements, or new characters.
---

Read docs/ART_DIRECTION.md first. Keep a 1990s arcade identity: bold silhouettes, restrained pixel palette, warm signals against cool scenery, and compact game UI. Design the screen composition before implementing components. Keep the game surface dominant. Use a 640×360 logical canvas and nearest-neighbor scaling; UI text can use crisp browser typography.

For new work, define purpose, focal point, silhouette, palette and behavior in motion. Use existing art tokens, not a generic dashboard template. Draw original assets; do not substitute emoji or unrelated stock graphics. Gameplay hazards must be readable without color alone. Review title, tutorial, play and end states at desktop and narrow widths. Follow the visual-review skill before completing visual changes.
