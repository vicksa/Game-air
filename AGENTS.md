# Hand Quest working agreement

Before visual work, read `.agents/skills/art-direction/SKILL.md`. For sprites read `.agents/skills/sprite-animation/SKILL.md`. After visual work use `.agents/skills/visual-review/SKILL.md`. These project skills are local guidance, not installed plugins.

Use Portuguese for player-facing copy. Keep camera processing on the user's device. Preserve separate tracking, gesture interpretation and game commands. Do not introduce network uploads of camera data. Run `npm test`, `npm run build` and `npm run test:e2e` for gameplay changes. Never claim physical webcam validation from mocked tests.
